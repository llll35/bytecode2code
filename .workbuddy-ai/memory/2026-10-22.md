## 修复的缺陷（新发现，非原清单）
`pyvers/selftest.py`：无解释器时 `interp.interpreter_magic()` 返回 None，
`test_versions()` 直接 `magic.hex()` → `AttributeError: 'NoneType' object has no attribute 'hex'`；
`test_interpreters()` 把 None 传给 `os.path.isfile()`。修复：main() 提前检测
`available_versions()` 为空 → 打印指引并 return 0；两处加 None 守卫。
实测：空 embed dir 优雅退出 0；真实环境回归 373 项 / 3 失败（与基线一致）。
